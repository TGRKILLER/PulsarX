# PulsarX Toolkit

A small, offline-ready collection of everyday text and data tools.

## Open it

1. Extract `PulsarX-Multitool.zip`.
2. Open `multitool/index.html` in a modern web browser.

No installation, account, network connection, or external libraries are needed. All processing happens in your browser; input is not sent anywhere.

## Included tools

- Text: uppercase, lowercase, title case, and word/character/line count.
- JSON: format and minify.
- URL: encode and decode.
- Base64: encode and decode UTF-8 text.
